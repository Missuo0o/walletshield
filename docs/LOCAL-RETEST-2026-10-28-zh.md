## 尚不能声称解决的内容

1. **AI 准确率没有独立校准。** 测试通过、有引用、能出分，都不能给出真实漏报率或损失概率。需要独立标注、留出的真实样本测评，才能做准确率承诺。
2. **没有覆盖所有钱包自动入口。** 本轮没有人工重做浏览器扩展安装/确认；权限、会话、UserOperation 在钱包未提供 hook 时仍需文档中的主动接入。非 EVM 和任意自定义协议不属于完整自动覆盖范围。
3. **取证仍有边界。** 未来签名消费、复杂不透明调用、非标准资产、身份、未来链状态与完整资产发现不能保证。本轮本地测试没有认证公网 RPC/trace 的全面可用性或外部情报实时性。分叉降级测试成功不代表每家 RPC 都支持所需历史状态。
4. **仍有上游依赖告警。** 全量审计为 **14 个低危受影响包条目**，本次没有中危/高危/严重条目；主要来自 [deepmerge](https://github.com/advisories/GHSA-gcqx-w48m-w2h4) 与 [elliptic](https://github.com/advisories/GHSA-848j-6mx2-7j84)，公告仍无修复版。`--omit=dev` 的选定依赖集为 0 条，但项目构建/启动仍使用开发依赖，不能据此说部署依赖零风险。没有为了清零告警而强行降级 CLI 或换入未经验证的版本。

修复后的本地版本可以继续受控测试，但以上边界会影响可靠性和对外承诺，不能说已经保护所有操作。是否同步 VPS，由你决定。若之后批准，先备份线上 SQLite，再更新后端/构建并重启，核对登录后的额度、历史和新钱包提示。本次没有修改 Snap 入口源码或权限，不因这次修复本身要求重新发布 npm Snap。
