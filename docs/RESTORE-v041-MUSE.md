# 恢复 0.4.1 与 Muse Wonder 适配 · 2026-10-22

根据用户最后确认的范围，停止开发新的钱包实验版本，恢复完整的原 0.4.1 源码快照，仅迁移模型供应商及配置方式，并修正启动版本检查和配置说明。

## 恢复内容

原有网页导航“钱包防护 / 授权测试 / 检查记录 / 钱包接入”、MetaMask Flask 测试钱包连接、Snap 安装/配对、原生 Anvil 本地链、TEST-USD 资金准备、历史关联、交易/签名检查与原来的协议取数、模拟路径均恢复。

这不是重新承诺覆盖全部风险。原 0.4.1 的部分覆盖与手动入口限制仍适用；其他类别的演示按钮不等于对应真实钱包操作已经构造和验收。没有加入新的通用 7702 自动签名入口。签后监控仍不启用，签署/拒绝仍由用户在钱包决定。

## 模型与 RPC

- 固定模型：Meta Muse Wonder `muse-wonder-1.0`。
- 固定接口：`https://api.meta.ai/v1/responses`；后端使用 Bearer `MODEL_API_KEY`、`store:false`、严格结构化输出及证据引用校验。
- Muse Key：`.local/meta.env`；开关 `ENABLE_META_AI=1`。旧 OpenAI Key 不再用于新请求，不自动回退其他供应商。
- Infura Key：`.local/rpc.env` 的 `INFURA_API_KEY`，自动生成 Ethereum 主网与 Sepolia 的 RPC；可用 `RPC_网络ID_URL` 指定其他可信端点。仅返回已配置网络 ID，不向网页返回含密钥的 URL。
- 本地 31337 无需 Infura，始终指向本机 Anvil。外部情报默认关闭；副本模拟保留开启配置。
- 配置文件按请求读取，保存后无需重启；尚未配置/请求失败时保留规则及缺口，并明确标记规则评分来源。
