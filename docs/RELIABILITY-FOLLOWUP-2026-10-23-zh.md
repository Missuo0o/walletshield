# 评分可靠性与 trace 改进 — 2026-10-23

[English](RELIABILITY-FOLLOWUP-2026-10-23.md) · [脱敏结果](reliability-followup-2026-10-23.json) · [之前的完整验证](FULL-VALIDATION-2026-10-23-zh.md)

本轮针对有效弃权、回复被拒绝、准确率未测量和公网 trace 缺失进行改进，补上可运行的机制与测量工具。不代表每次都有数字、已经测得独立准确率，或代码能保证供应商提供所有接口。

## 本轮完成的修改

### 评分状态分开显示

网页、历史、实验室与 Snap 区分：有合规数字、证据不足、模型回复被拒绝、连接失败、分析中、未运行和无需评分。旧报告只改变展示分类，不改写原始判断；失败结果不能继续显示遗留模型解释为已接受分析。

参数完整、严格白名单内的只读查询，例如 `eth_getBalance(地址, 区块)`，保存报告但标为 **Not applicable · Read-only query**，不调用 Muse、不消耗模型额度。这只说明它不请求转账、签名或新增资产权限，不检查账户隐私披露和返回数据是否可信。未知 `wallet_get*`/`eth_get*` 扩展、非法参数和脱敏后的不完整输入不能获得豁免；复杂调用仍正常分析。原有定性风险不会因为无数字而被清除。

### 模型回复与证据

模型新格式为 `walletshield-selection-v1`：选择精确 `selected_fact_ids`，不用重复抄写整份主体、数值、来源、链、区块和时间。后端从本请求的不可变事实目录解析这些 ID，仍保存为原有 `walletshield-facts-v1`。陌生/重复 ID、错误引用、维度不相关、弃权矛盾和无依据断言仍被拒绝；旧完整事实格式仍走原校验。不会修改 AI 的数字、判断或文字来通过检查。

补齐了账户、链和 SIWE 来源比较的结构化值。以前部分不匹配只有标题和状态，模型看得见风险提示，却没有可引用的实际比较字段；现在 owner/signer、来源 origin、声明域名/URI 和支持的结构字段都能作为有范围的事实引用。这不等于验证了网站身份或服务器登录 nonce。

模型引用实际 owner/signer 不匹配时，校验器不再仅因解析器状态为 warning 就丢弃该观察；仍必须有正确地址及明确不相等字段。缺少信誉、泛泛的 warning 不足以支持高身份风险。不匹配也不等于证明诈骗，或证明合约账户不可能允许不同签名者。

输出修复与暂时性 HTTP 错误共用最多一次额外请求。HTTP **500/502/503/504** 可以在独立原子额度预留成功、仍有至少五秒时补试；两次合计仍限 **50 秒**，第二次最多 25 秒，一个分析最多两次模型请求。认证、额度、429、超时、普通网络错误、拒答和有效弃权不会自动重试。错误正文不公开，增加机器可读 `failureKind`、`attempts`、`repaired`。成功回复的 token 用量不会冒充之前失败请求的完整账单。

### RPC trace 回退

交易分析先在主 RPC 尝试 **`debug_traceCall` → `trace_call`**，都不可用时，可在后端配置的专用端点尝试。专用端点必须先与主端点核对链、区块高度、哈希和时间；trace 后再次核对专用与主端点哈希。状态不一致就保持未知，不换一个状态制造成功。

限制为总计 14 秒、单请求 1.8 秒、响应 750 KB、128 帧、深度 20。空/畸形/绑定错误、缺失子树和截断均保留缺口。不删除原始不支持字段来模拟替代交易，也不会发送真实交易。最多四帧调用摘要作为结构化事实送给 Muse，只支持 execution 维度，不证明身份、完整资产变化或安全。

可在本机 `.local/rpc.env` 配置以下可选项：

```dotenv
# 把占位符换成运营者选择且实际支持 tracing 的可信端点。
# 密钥只放后端，不进入网页代码。
TRACE_RPC_1_URL=https://YOUR_TRUSTED_MAINNET_TRACE_ENDPOINT
TRACE_RPC_11155111_URL=https://YOUR_TRUSTED_SEPOLIA_TRACE_ENDPOINT
```

对应主 RPC/Infura 必须已配置，本轮没有替你购买服务或配置陌生供应商。31337 仍使用自有本地节点。状态和错误不暴露端点 URL。专用服务会收到必要的未签名交易字段，应只配置已获授权、可信的服务。

实际本地 Anvil trace 成功。当前 Infura 主网与 Sepolia 两种方法都返回 **method_unsupported**，属于供应商能力缺失，代码不能代为开通。需要实际支持 trace 的可信端点，才能补上这个外部缺口；其他状态读取、普通调用和隔离分叉证据按各自结果独立保留。Public networks 面板探测主端点，交易证据另行记录专用回退。

### 独立评估工具

新增 `npm run evaluate:independent`，比较冻结的人工/外部审核标签与保存的模型预测，核对标签/证据哈希、审核和来源声明、时间、留出分组和声明的调参泄漏。统计分类、AUROC 排序、覆盖率，并分开失败、弃权、无需评分和缺失结果；相关案例保留分组数，不伪装成独立统计样本。

它不调用模型/RPC，也不改变生产评分。附带例子明确是合成格式示例。**目前尚未得到独立准确率数字**：仍需实际独立审核标签、合理抽样与留出集预测。当前 0–100 是风险指标，没有明确的损失事件/时间窗口概率含义，不能直接除以 100 声称完成概率校准。完整流程见[独立评估说明](INDEPENDENT-EVALUATION-zh.md)。

## 验证结果

- Node.js 24.19.0 下 **495/495 单元/回归测试通过**，含事实选择、结构化比较、状态、只读、trace 和独立评估新增用例。
- 网页/Snap 生产构建与类型检查通过，Snap 显示更新后重建校验和。
- 隔离 V3/状态集成 **23 个内部场景通过**。
- 原有离线合成校验与在线 Muse 准确率继续分开；独立评估合成格式示例成功运行，零模型/RPC 调用。
- 本地 Anvil 实际只读 trace 成功，保留一帧，没有提交交易。

针对之前失败的四类情况，各补测两次，最多允许 16 次请求；实际 **9 次 Muse 调用**（含一次输出修复），得到 **8/8 合规回复：7 个数字、1 个有效弃权**：

| 类别 | 第一次 | 第二次 |
| --- | ---: | ---: |
| SIWE 登录 | 52 | 62 |
| NFT 订单签名 | 有效弃权 | 55 |
| SIWE 来源/域名不匹配 | 74 | 82，修复一次后通过 |
| Permit owner 不匹配 | 76 | 68 |

这属于针对性工程补测：使用当前确定性比较和历史非规则观察，原始链区块和时间不改写，不是重新走完整钱包模拟。每次检查时间和证据包哈希不同，也不是逐字节相同输入的重复性研究或独立标注基准。启用执行环境网络访问之前，另有八次立即连接失败的诊断，单独保留，没有被改成模型成功。

**数字波动仍需正视**：输出合规不等于判断确定不变。订单案例一次弃权、一次给分。本轮改善回复可靠性并补上可测量机制，没有宣称消除所有模型差异，也没有取平均、挑选喜欢的答案、加固定分数或去掉合理弃权。

## 使用新版本

`npm run build` 后重启开发服务，在 Wallet setup 点击 **Reload and pair Snap**。不必清空本地链或历史。旧报告保留原数字和钱包结果。trace 需要实际支持接口的服务，准确率需要文档规定的独立标签；这两项都不能用一个开关或编造百分比替代。
