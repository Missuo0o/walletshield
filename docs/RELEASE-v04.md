# WalletShield 0.4：签名前的 AI 风险提示

当前目标是：钱包请求 → 按操作选择取数工具 → 取得证据并记录缺失 → OpenAI 风险评分与解释 → 用户自行决定是否签名。不包含签后监控、强制阻止或自动签名。

“签前”包含转账前。转账、兑换、授权、存款、借款等交易都需要账户授权执行；普通自托管账户通常要先签名再广播。Permit 和订单等消息签名则可能暂时不发交易，却授权第三方以后执行。智能账户、会话与批量执行可能采用不同授权方式，不能假设每一步都会出现独立签名弹窗。

## 当前覆盖到什么程度

| 操作 | 目前取得或分析的数据 | 尚不能确定的内容 |
|---|---|---|
| 原生币转账 | 网络、区块、余额、目标代码；可选副本执行、净余额与费用参数 | 对方身份、转账目的、链下诈骗与未来行为 |
| ERC-20 / NFT 转移 | 常用转移方法、数量或编号、接口标准、可识别资产差异 | 非标准代币、无事件资产、全部内部影响 |
| 授权与撤销 | ERC-20、NFT 单项 / operator、部分 Permit2 额度，既有权限 | 自定义权限及未来权限消费 |
| 兑换 | 常用 V2 / V3 参数、路由 / 接收人 / 最低产出；V2 有界副本往返测试 | 全部聚合器、V3 卖出验证、MEV、未来管理员行为 |
| 金库 | ERC-4626 风格 asset、总资产 / 份额、preview、max 接口 | 协议身份、资产估值、未来提现保证；同名 ABI 可能属于其他协议 |
| 借贷与抵押 | Aave 风格账户抵押 / 债务、LTV、健康因子、储备配置原值 | 操作后完整清算模型、预言机可信度、全部借贷协议 |
| 质押、流动性 | 部分常见方法、金额、接收方、期限；父交易副本执行与可识别资产 | 奖励可持续性、锁仓 / 罚没、LP 估值、未来退出 |
| 跨链与领取 | 部分常见桥 / 领取方法、代币、金额、收款地址 | 目标链到账、桥验证者、项目真实性 |
| 合约控制与部署 | 控制者 / 角色 / 升级候选，代码哈希、ERC-1967 常见槽、可读 owner / paused | 完整源码审计、隐藏管理员、自定义代理、存储布局兼容性 |
| 消息、登录、订单、Permit | 消息 / 类型与财务参数摘要、domain / 网络、部分 nonce 与编码校验 | 所有签名变体、未来消费、完整订单履约条件 |
| 权限、会话、UserOperation、批量 RPC | 主动提交时提取白名单参数、地址、权限范围、期限、字节摘要；统一进入 AI | 当前 Snap 没有通用 RPC 截获入口；未执行 bundler / paymaster 或全部自定义会话语义 |
| 未识别操作 | 保留 selector、长度、可读参数和证据缺口，仍进入 AI 阶段 | 不会因为进入 AI 就变成已理解或已安全 |

自动 Snap 入口目前是 MetaMask 提供的 EVM transaction / signature insights。其他钱包、移动端、Bitcoin / Solana、设备恶意软件、私钥泄露、交易所内部操作尚未接入。网页与 Snap 都只是风险提示。

## AI 连接状态

用户已经在本机保存 Key。2026-10-21 的固定合成样本实测两次返回 HTTP 429；第二次用于确认新的错误提示。没有取得成功的模型输出，未生成真实 AI 分数。用户选择稍后检查 API 平台额度 / 限流，本次不再重试。

页面中的“已配置”仅表示后端读到了非空配置，不表示 API 可调用。当前 75 / 100 等历史数字若标为“规则”，不是 AI 分数，也不是资金损失概率。

检查 [API Billing](https://platform.openai.com/settings/organization/billing/overview) 与项目 Limits。ChatGPT 订阅和 API 账单分别计算。确认额度 / 限流正常后，在网页展开“如何启用 AI 与真实数据”，点击“测试 AI 连接（固定合成样本）”。成功时应出现“AI 分析：已完成”和“AI 风险指标”。Key 只保存在 `.local/ai.env`，不要放到网页代码、聊天或截图中。

真实链的数据仍需后端配置 `RPC_网络ID_URL`。本机当前仅配置 31337；Key 本身不会提供其他链的 RPC 或补齐情报源覆盖。可选 `ENABLE_EXTERNAL_LOOKUPS=1`、`ENABLE_FORK_SIMULATION=1`；不支持或失败会保留未知。

## 模型会收到什么

白名单证据包括网络、清理后的来源域名、用户填写的用途 / 背景、公开地址、value / selector / 长度、费用、已解析财务参数、工具选择、节点与情报结果、模拟变化和缺失项。不会主动获取助记词、私钥、已生成签名、整份钱包历史或 RPC 密钥。未知 RPC 的原始字节与任意字段不直接发送；最多提取有限层数和字段，限制会写入摘要。

用户用途与未签名消息仍可能含私人信息；调用外部模型前应确认内容适合传给 OpenAI。`store:false` 不代表零留存承诺。OpenAI Key 仅用于后端调用固定 Responses API。

AI 输出必须包含证据引用、风险指标、理由、建议和缺失数据。凭空引用、压低已知风险、无证据宣称 honeypot 的结果会被拒绝。信息太少可以没有分数；不能为了每次都有数字而伪造确定性。每天最多 30 次模型尝试，含失败尝试。完整事实不能单靠提示词获得。

现有服务无需重启链：刷新网页即可。用户可在“钱包接入”重新加载 0.4.0 Snap；需要钱包确认时由用户操作。此次未替用户安装、签名或授权交易。
